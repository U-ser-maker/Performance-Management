# 接口文档

> 基础路径：`/api`  |  鉴权：Sa-Token，请求头 `satoken: xxx`  |  统一返回：`Result<T>`

## 1. 统一返回结构

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，200成功 |
| msg | string | 提示信息 |
| data | object | 数据 |

## 2. 认证接口

### 2.1 登录
`POST /api/auth/login`

请求：
```json
{ "username": "admin", "password": "123456" }
```
返回：`{ token, userInfo }`

### 2.2 登出
`POST /api/auth/logout`

### 2.3 获取当前用户信息
`GET /api/auth/info`

## 3. 组织接口

### 3.1 部门树
`GET /api/system/dept/tree`

### 3.2 部门CRUD
- `GET /api/system/dept/list`
- `POST /api/system/dept` 新增
- `PUT /api/system/dept` 修改
- `DELETE /api/system/dept/{id}` 删除

### 3.3 员工管理
- `GET /api/system/user/page?pageNum=1&pageSize=10&deptId=&keyword=`
- `POST /api/system/user` 新增
- `PUT /api/system/user` 修改
- `DELETE /api/system/user/{id}` 删除
- `PUT /api/system/user/resetPwd` 重置密码

### 3.4 岗位管理
- `GET /api/system/post/list`
- `POST /api/system/post`
- `PUT /api/system/post`
- `DELETE /api/system/post/{id}`

### 3.5 角色管理
- `GET /api/system/role/list`
- `POST /api/system/role`
- `PUT /api/system/role`
- `DELETE /api/system/role/{id}`
- `PUT /api/system/role/{id}/menus` 分配菜单

### 3.6 菜单树
`GET /api/system/menu/tree`

### 3.7 字典
- `GET /api/system/dict/type/{dictType}`
- `GET /api/system/dict/list`

## 4. 指标库接口

- `GET /api/indicator/page?pageNum=1&pageSize=10&type=`
- `POST /api/indicator` 新增
- `PUT /api/indicator` 修改
- `DELETE /api/indicator/{id}`
- `POST /api/indicator/import` Excel导入
- `GET /api/indicator/export` Excel导出

## 5. 绩效方案接口

- `GET /api/template/page`
- `POST /api/template` 新建
- `PUT /api/template` 修改(草稿态)
- `DELETE /api/template/{id}`
- `GET /api/template/{id}` 详情
- `POST /api/template/{id}/publish` 发布方案
- `POST /api/template/{id}/archive` 归档方案

## 6. 员工绩效接口

- `GET /api/perf/my/list` 我的绩效列表
- `GET /api/perf/{id}` 绩效详情
- `POST /api/perf/{id}/goal` 保存绩效目标
- `POST /api/perf/{id}/selfEval` 提交自评
- `GET /api/perf/{id}/result` 查看结果
- `POST /api/perf/{id}/appeal` 发起申诉
- `GET /api/perf/archive` 绩效档案

## 7. 主管绩效接口

- `GET /api/perf/subordinate/list` 下属绩效列表
- `PUT /api/perf/{id}/goalReview` 目标审核
  ```json
  { "pass": true, "comment": "同意" }
  ```
- `POST /api/perf/{id}/managerScore` 主管打分
  ```json
  { "details": [{"indicatorId":1,"score":90,"comment":"表现优秀"}] }
  ```

## 8. HR 报表接口

- `GET /api/report/deptDistribution` 部门绩效等级分布
- `GET /api/report/deptAverage` 部门平均分
- `GET /api/report/personalTrend?userId=` 个人绩效趋势
- `GET /api/report/export` 批量导出

## 9. 申诉审批接口

- `GET /api/appeal/list` 申诉列表
- `PUT /api/appeal/{id}/managerApprove` 主管审批
- `PUT /api/appeal/{id}/hrApprove` HR审批
