## 2. 典型页面布局

### 2.1 工作台
- 顶部：欢迎语 + 当前考核周期提醒
- 左侧：待办卡片（待审核目标、待打分、待处理申诉）
- 右侧：我的绩效概览（最近一次绩效分数、等级）

### 2.2 绩效方案编辑页
- 基本信息：名称、周期、权重、等级区间
- 指标配置：选择指标 + 设置权重（权重和=1）
- 考核对象：按部门/岗位选择员工
- 操作：保存草稿 / 发布

### 2.3 打分页面
- 顶部：员工信息 + 方案信息
- 中部：指标列表表格（指标名、权重、自评分、主管分、评语）
- 底部：自动计算的总分预览 + 提交按钮

### 2.4 报表大屏
- 上：公司总体绩效等级分布饼图
- 中左：各部门平均分柱状图
- 中右：个人绩效趋势折线图
- 下：明细数据表
