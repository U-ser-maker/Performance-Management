# 企业通用绩效管理平台 PRD（产品需求文档）

## 1. 文档说明

### 1.1 目的
本文档定义企业通用绩效管理平台的产品需求，作为设计、开发、测试的依据。

### 1.2 范围
覆盖组织人事、绩效指标库、绩效方案、绩效计划、绩效评估、绩效结果、绩效申诉、绩效档案、可视化报表等核心模块。

---

## 2. 项目背景与目标

### 2.1 背景
传统绩效考核依赖 Excel 与邮件流转，存在流程不透明、数据分散、计算易出错、难以追溯等问题。需要一套系统化平台支撑全公司绩效考核闭环。

### 2.2 目标
- 绩效流程线上化：方案配置 → 目标填写 → 审核 → 自评 → 主管打分 → 结果计算 → 申诉归档。
- 计算自动化：按权重自动加权计算总分，自动匹配绩效等级。
- 数据可视化：部门分布、个人趋势、公司大盘。
- 权限精细化：基于 RBAC + 数据权限实现角色隔离。

---

## 3. 用户角色与权限

| 角色 | 权限范围 |
|------|----------|
| 超级管理员 | 全部系统权限，维护部门/员工/角色菜单/数据权限 |
| HR 绩效管理员 | 指标库维护、方案配置、结果汇总、导出报表（全公司） |
| 部门负责人 | 下属目标审核、打分、查看本部门绩效 |
| 普通员工 | 填写目标、自评、查看本人结果、发起申诉 |
| 高管 | 全公司绩效大盘、部门报表查看 |

### 3.1 数据权限规则
- 普通员工：仅本人数据。
- 部门主管：本部门及子部门下属数据。
- HR / 高管：全公司数据。

---

## 4. 功能需求

### 4.1 组织人事模块
- **部门管理**：树形结构，支持新增/编辑/删除/排序。
- **员工管理**：CRUD，关联部门、岗位、直属主管。
- **岗位管理**：岗位 CRUD。
- **角色菜单权限**：角色绑定菜单与按钮权限。
- **数据权限**：按角色配置数据范围。

### 4.2 绩效指标库
- 指标 CRUD，分类：KPI / GS / 能力 / 态度。
- 岗位绑定指标。
- Excel 批量导入 / 导出。

### 4.3 绩效方案管理
- 新建方案：名称、考核周期、考核对象范围、自评权重、主管权重。
- 配置绩效等级分数区间（A/B/C/D）。
- 绑定指标及权重。
- 发布方案（批量生成员工绩效主记录）。
- 归档方案。

### 4.4 绩效计划
- 员工填写绩效目标（针对方案绑定的指标）。
- 主管审核：通过 / 驳回 + 审核意见。

### 4.5 绩效评估打分
- 员工自评：对每条指标打分 + 评语。
- 主管打分：对每条指标打分 + 评语。

### 4.6 绩效结果
- 后端自动计算：`最终得分 = 自评得分 × 自评权重 + 主管得分 × 主管权重`。
- 自动匹配绩效等级 A/B/C/D。
- HR 开放结果查看后员工可见。
- 批量导出。

### 4.7 绩效申诉
- 员工提交申诉材料。
- 多级审批（主管 → HR）。
- 申诉通过可更新分数，保留版本日志。

### 4.8 绩效档案
- 员工历史所有绩效考核记录存档。
- 按时间检索。

### 4.9 可视化报表
- 部门绩效等级分布饼图。
- 部门平均分柱状图。
- 员工个人绩效趋势折线图。

---

## 5. 核心业务规则

1. **绩效总分计算**：`最终得分 = 自评得分 × 自评权重 + 主管得分 × 主管权重`，权重之和 = 1。
2. **等级匹配**：按方案配置的分数区间匹配 A/B/C/D。
3. **方案发布冻结**：方案发布后考核规则不可修改；发布时批量生成参与员工绩效主记录。
4. **数据权限隔离**：普通员工只查自己，部门主管仅访问本部门下属。

---

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 列表查询 < 500ms，报表 < 2s |
| 安全 | Sa-Token 鉴权，密码 BCrypt 加密，接口权限校验 |
| 可用性 | 支持 Excel 导入导出，操作友好 |
| 可扩展性 | 模块化单体，便于未来拆分为微服务 |

---

## 7. 技术选型

- **前端**：Vue3 + Element Plus + VueRouter + Pinia + Axios + ECharts
- **后端**：Spring Boot 2.7 + MyBatis-Plus + Sa-Token
- **数据库**：MySQL 8.0
- **可选**：Redis（缓存）、MinIO（附件）
